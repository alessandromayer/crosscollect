# CrossCollect

Cross-border debt recovery SaaS platform connecting creditors with Brazilian debtors.

## Features

- **Creditor Portal** — intuitive interface for case management
- **WhatsApp Automation** — automated outreach via Twilio
- **Payment Integration** — Asaas for Brazilian Pix and card processing
- **Database Management** — Serasa integration for debtor verification
- **Email Workflows** — automated notifications via Resend

## Tech Stack

- **Frontend:** Next.js, React, TypeScript
- **Backend:** Supabase (PostgreSQL)
- **Integrations:** Twilio WhatsApp API, Asaas Payments, Serasa
- **Hosting:** Vercel
- **AI:** Claude (workflow orchestration)
